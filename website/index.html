Make sure the frame is powered on and nearby.

This browser can't use Bluetooth

Web Bluetooth isn't available here (iPhone/iPad Safari doesn't support it yet). You can still set up and control your frame from the same WiFi:

  1. On your phone's WiFi settings, join the hotspot DigiFrame (password digiframe123).
  2. Open http://192.168.4.1 — the frame's own dashboard opens with the same controls.
  3. Enter your home WiFi there. Once the frame is online you can reach the dashboard at http://digiframe.local.

For remote control from anywhere, use the Telegram bot (see the project README).

Or open this page in Chrome or Edge on Android, Windows, macOS or Linux to use Bluetooth.
